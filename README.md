Java assignments and exercises from the CS4512 Imperative Programming
module of the LM051 degree at the University of Limerick.

## Contents

- A NetBeans Swing spreadsheet application (`ExcellApp`),
  built with Ant (`build.xml`). `Excellerator` holds sample
  spreadsheets.
- `Mp3`: an MP3 database program (`player.Mp3Database`) with scripts
  to compile, package and run it.
- `javaphone2` and `javaphoneW1`: mobile phone simulation exercises
  with a contact list and word lists.
- `OurMethods`, `queueOfInts` and the top-level `.java` files:
  smaller exercises on types, casting, recursion, queues and past exam
  questions.

## Tech

- Java, with some projects set up for NetBeans or BlueJ

## Running

Most exercises are single files that compile with `javac`. For the MP3
database:

```sh
cd Mp3
./compile-run.sh
```
